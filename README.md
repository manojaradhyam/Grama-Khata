# Grama-Khata

Grama-Khata is a simplified digital ledger and micro-finance management application designed for small village grocery stores and local vendors. The application helps shop owners maintain customer credit records digitally instead of using traditional handwritten books ("Vahi").

## Problem Statement

Many small businesses in villages still maintain credit transactions manually in notebooks. This creates several problems:

* Credit records can be lost or damaged
* Customers may forget pending balances
* Manual calculations may lead to errors
* No proper digital reminder system exists
* Maintaining physical books is difficult and time-consuming

Grama-Khata solves these problems by providing a simple, user-friendly digital ledger system.

# Installation

## Clone the Repository

```bash
git clone https://github.com/manojaradhyam/Grama-Khata.git
```

## Navigate to Project Folder

```bash
cd Grama-Khata
```

## Install Dependencies

```bash
npm install
```

## Run the Project

```bash
npm start
```
